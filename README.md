# Caixa da Família

App de controle financeiro da família, instalável no celular (PWA).

- **App:** `index.html`, publicado pelo GitHub Pages. Instale no iPhone pelo Safari em *Compartilhar → Adicionar à Tela de Início*.
- **Dados:** ficam numa planilha Google do dono, por meio do servidor em `apps-script/Code.gs` (Google Apps Script).
- **Voz:** atalhos do app Atalhos do iPhone chamam o servidor (`acao=lancar` e `acao=limite`).

Este repositório não guarda nenhum dado financeiro nem senha. O endereço do servidor e a chave da família são digitados no próprio celular, na primeira abertura do app.
